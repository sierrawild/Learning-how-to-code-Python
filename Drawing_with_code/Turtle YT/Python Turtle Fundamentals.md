# Season 1: Python Turtle Fundamentals

A beginner-friendly introduction to programming through drawing, patterns, and creative projects.

| Episode | Main Concept | Project | Proposed Title |
|----------|-------------|----------|----------|
| 1 | Basic Turtle Commands | Draw a square using `forward()` and `left()` | Draw Your First Square in Python |
| 2 | Variables | Make the square resizable without rewriting code | Make Your Square Any Size with Variables |
| 3 | Loops | Draw a square using repetition instead of duplicated code | Stop Repeating Yourself with Loops |
| 4 | Nested Loops | Create grids, patterns, and simple computer-generated art | Create Computer Art with Patterns |
| 5 | If Statements | Build a checkerboard using conditional logic | Build a Checkerboard with If Statements |
| 6 | Loop Variables (`i`) | Create growing spirals and geometric art | Create Amazing Spirals with One Loop |
| 7 | Functions | Create reusable drawing tools such as `draw_square()` | Build Your First Drawing Function |
| 8 | Parameters | Create flexible functions that can draw different shapes and sizes | Make Your Functions More Powerful |
| 9 | Pen Up, Positioning, and Composition | Build a face generator using previously learned concepts | Build a Face Generator in Python |
| 10 | Useful Turtle Features | Explore writing text, mouse clicks, animation control, and performance improvements | Hidden Turtle Features Every Beginner Should Know |

## Learning Journey

**Square → Patterns → Checkerboards → Spirals → Drawing Tools → Face Generator**

# Season 2: Creative Coding with Python Turtle

Building on the fundamentals from Season 1 to create generative art, procedural drawings, and mathematical patterns.

| Episode | Main Concept | Project | Proposed Title |
|----------|-------------|----------|----------|
| 1 | Random Numbers | Generate random values and experiment with unpredictability | Add Randomness to Your Python Art |
| 2 | Random Colours | Create colourful procedural artwork | Infinite Colour Combinations with Python |
| 3 | Generative Dot Art | Create dot paintings inspired by real artists | Create Dot Art Like a Modern Artist |
| 4 | Procedural Face Generator | Generate unique faces using randomness | Build a Face Generator That Never Draws the Same Face Twice |
| 5 | Random Walks | Simulate wandering paths and create abstract art | Let Python Decide Where to Draw |
| 6 | Recreating Famous Art | Take inspiration from artists such as Yayoi Kusama and Damien Hirst | Recreate Famous Art with Python Turtle |
| 7 | Introduction to Fractals | Understand self-similar patterns and mathematical art | What Makes a Fractal a Fractal? |
| 8 | Chaos Game | Use randomness to generate fractal patterns | Create a Fractal with Pure Randomness |
| 9 | Sierpiński Triangle | Build one of the most famous fractals in mathematics | Create a Sierpiński Triangle with Python |
| 10 | Generative Art Showcase | Combine techniques from the entire season into an original artwork generator | Build Your Own Generative Art Machine |
